\section{Introduction}

USENIX calls state the page limit as ``N pages, not including
references''~\cite{usenix}. Everything else is inside the budget, the
acknowledgments included, and a paper that fits on the last page only until
the acknowledgments are written has a problem the author finds out about at
the deadline. paperkit counts the pages the way the chairs
do~\cite{reproducible}: the budget ends where the references start, and a
references section that starts mid-page counts that page.

This example shows the project shape for such a paper. The \texttt{usenix}
profile has one thing to say, that the acknowledgments count, and the file
writes it out; the rest is the common configuration.
